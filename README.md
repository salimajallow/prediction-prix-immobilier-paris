# Prédiction des prix des appartements à Paris

## Présentation du projet

Ce projet consiste à développer un modèle de Machine Learning capable de prédire le prix de vente des appartements à Paris à partir de leurs caractéristiques immobilières.

L'objectif est d'étudier les facteurs qui influencent les prix immobiliers et de construire un modèle prédictif basé sur la régression linéaire.

## Objectifs
- Explorer et comprendre les données immobilières.
- Réaliser le nettoyage et le prétraitement des données.
- Effectuer une analyse exploratoire (EDA).
- Identifier les variables pertinentes pour la prédiction.
- Construire un modèle de régression linéaire.
- Évaluer les performances du modèle.

## Technologies utilisées
- Python
- Google Colab
- Pandas et NumPy
- Matplotlib et Seaborn
- Scikit-learn

## Variables étudiées

- Arrondissement
- Surface en m²
- Surface Carrez
- Nombre de pièces
- Nombre de lots
- Nombre de dépendances
- Prix de vente

## Modélisation

Un modèle de régression linéaire a été entraîné sur les données immobilières, avec une séparation entre les données d'entraînement et de test.

## Perspectives d'amélioration

- Tester des modèles plus avancés (Random Forest, Gradient Boosting).
- Optimiser les hyperparamètres.
- Comparer les performances de plusieurs algorithmes.
- Développer une interface interactive de prédiction avec Streamlit.
